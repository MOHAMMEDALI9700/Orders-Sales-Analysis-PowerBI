Orders & Sales Analysis Dashboard — Power BI

Project Overview

This project analyzes sales and profit data using Microsoft Power BI. The dashboard helps identify sales trends, profitable products, customer performance, and regional sales patterns.

Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization
- Data Cleaning and Transformation

Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Order Value
- Profit Margin %
